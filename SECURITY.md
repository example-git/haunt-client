# Security policy

Haunt Client has not received an independent security audit. Encrypted direct
messages, local backups, saved sessions, desktop updates, browser storage, and
server-provided identity information have distinct trust boundaries documented
in this repository.

## Supported versions

Security fixes target the current `main` branch and the newest published client
release. Older desktop baselines may need replacement rather than an in-place
application update.

## Reporting a vulnerability

Use this repository's GitHub **Report a vulnerability** feature. If it is
unavailable, contact a repository owner privately. Do not open a public issue
for a suspected vulnerability.

Include the affected commit and platform, impact, prerequisites, reproduction
steps, and mitigation if known. Never attach real session material, message
contents, private keys, recovery data, or signing credentials. The project does
not currently promise a response SLA or bug bounty.
